# 🎨 YouTube SEO Generator — Frontend

A modern, responsive React + Vite application with glassmorphic dark mode UI to generate YouTube `#hashtags`, keywords, and SEO scores.

---

## 🚀 Features

- **2 Input Modes**: YouTube URL analysis and Video Script analysis.
- **Click-to-Copy**: Instant copy buttons for individual tags, title suggestions, or all hashtags.
- **Glassmorphic Dark UI**: Custom CSS with animated gradients, circular SEO score gauges, and responsive mobile layouts.

---

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment
Create a `.env` file:
```env
VITE_BACKEND_URL=http://localhost:5000
```

### 3. Run Dev Server
```bash
npm run dev
```

App runs on `http://localhost:5173`.
